# Совместимость сред

Ядро (AGENTS.md, skills/, knowledge/, scripts/) одинаковое для всех сред.
Здесь фиксируем, что каждая среда реально поддерживает, и какие адаптеры ей нужны.

## Как проверять

1. Открыть репозиторий в среде.
2. Спросить: «Что ты умеешь и с чего начнёшь?» — ответ должен опираться на AGENTS.md.
3. Попросить: «Покажи статус примера projects/_example» — агент должен прочитать state.json.
4. Проверить субагентов, hooks и MCP, если среда их заявляет.
5. Записать результат в таблицу ниже.

## GigaCode: если понадобится

Не проверялся. Субагенты для него уже лежат в `.gigacode/agents/` (`python scripts/sync_agents.py`, модель — `inherit`). Проверить по шагам 2–3 выше; если AGENTS.md не подхватится — создать файл правил проекта GigaCode с одной строкой «Прочитай AGENTS.md и следуй ему».

Документация: https://gitverse.ru/docs/ai/ai-assistant-gigacode/gigacode-cli/

## Найденные расхождения и обходы

- **GitHub Copilot в VS Code:** нет хука учёта токенов, агент сам не вызвал `cost.py add --chars`; стоимость записал только по просьбе «запиши стоимость через scripts/cost.py».
- **Ошибка в нашей записи:** 20.11 эту среду ошибочно отметили как «GigaCode, плагин VS Code» — в VS Code стояло постороннее расширение Gigacode (Gigaclear, утилита для yaml), а прогон шёл в чате Copilot. Исправлено 21.11 по истории сессии и `habit-test/log.md`.
- **Cursor:** в новой версии MCP, правила и субагенты перенесены в раздел Customize; проектный `.cursor/mcp.json` там не показан — сервер `strategist` добавляется вручную: команда `python`, аргумент — полный путь к `scripts/mcp_server.py`. Хука учёта токенов нет, как и в Copilot. На бесплатном тарифе хватило на правила и один этап.
- **Обе среды без хука забывали записать расход**, хотя правило есть в AGENTS.md. Теперь `state.py stage … done` сам печатает напоминание с готовой командой `cost.py add --chars`, если за этап в `cost.csv` не появилось строк (проверено в selftest).
