# scripts/

Команды CLI агента. Запуск из корня репозитория: `python scripts/<имя>.py -h` — подсказка.
Все скрипты читают и пишут файлы строго по `docs/architecture.md`, при ошибке печатают
понятное сообщение и завершаются с кодом 1.

| Скрипт | Что делает |
| --- | --- |
| `state.py` | состояние задачи: init, status, list, start, done, fail, wait, answer, stage, question |
| `fetch_source.py` | веб-страница → `sources/S00N.md` + запись в `sources.yaml` |
| `extract.py` | файл пользователя (PDF, DOCX, XLSX, CSV, MD, изображения, аудио) → источник |
| `evidence.py` | реестр утверждений: add (id и проверка схемы автоматически), revoke, list |
| `analyze.py` | профиль таблицы: типы, пропуски, периоды, дубли |
| `validate.py` | проверка схем, меток `[E…]`/`[P…]`, источников, синтетики, чисел без опоры |
| `revise.py` | какие записи и выводы затрагивают новые данные |
| `cost.py` | учёт токенов и денег, отчёт по этапам и моделям |
| `build_report.py` | сборка `report.md` с приложениями: утверждения, источники, стоимость |
| `hooks/claude_cost_hook.py` | хук Claude Code: автоматически пишет токены в `cost.csv` |
| `common.py` | общие функции |

Проверка на образце: `python scripts/validate.py _example` — должно быть «Проверка пройдена».
