# agents/

Субагенты — помощники для отдельных задач, со своим узким промптом и чистым контекстом.

| Файл | Когда вызывается | Зачем отдельно |
| --- | --- | --- |
| `red-team.md` | этап 04, на каждый вариант | не видит аргументов «за» — возражения не смягчаются |
| `auditor.md` | этапы 06 и 07 | не участвовал в работе — не «оценивает сам себя» |
| `respondent.md` | `skills/interview.md` | играет роль, не зная гипотез агента |

Это единственный источник правды. Копии для сред: `python scripts/sync_agents.py` →
`.claude/agents/` (Claude Code) и `.gigacode/agents/` (GigaCode CLI).
В средах без субагентов (например, Cursor) файл используется как промпт отдельного прохода
в новом чате: «Прочитай agents/red-team.md и действуй по нему для варианта …».
