# knowledge/templates/

Шаблоны результатов этапов. Агент копирует шаблон в папку задачи и заполняет.
Образец заполнения — `projects/_example/`.

| Шаблон | Этап |
| --- | --- |
| `brief.md`, `requirements.md` (если есть бриф с требованиями) | 01 |
| `situation.md` | 03 |
| `options.md` | 04 |
| `decision.md` | 05 |
| `product-strategy.md`, `comms-strategy.md` | 06 |
| `validation-plan.md`, `summary.md`, `deliverable.md` (если есть `requirements.md`) | 07 |
