# Пример задачи: образец форматов

> **Все данные здесь вымышлены.** Продукт «Привычка+», цифры и источники придуманы,
> чтобы показать, как выглядят файлы задачи. Не используйте их как факты.

Задача остановлена посреди этапа `03-research`: видно, как выглядят завершённые
этапы, упавший шаг, открытые вопросы, отозванная запись и синтетический ответ.

| Файл | Что показывает |
| --- | --- |
| `brief.md` | результат постановки |
| `state.json` | этапы, шаги (в т.ч. `failed`), открытые вопросы |
| `sources.yaml` + `sources/` | три источника разных типов |
| `evidence.jsonl` | все 4 типа записей и одна отозванная |
| `situation.md` | черновик картины ситуации с метками `[E…]` |
| `log.md`, `cost.csv` | журнал и расходы |
