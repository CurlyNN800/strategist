# План проверки

> Методика: `knowledge/methods/experiments.md`. Размеры выборок — `calc/pilot.py`. Пороги записаны до запуска и не меньше
> эффекта, который пилот способен различить к своей дате. Параметры проверки — решение команды [E081]; календарь — [E071].

## Проверка 0. Данные оператора до пилота (1-й квартал)

| Поле | Значение |
| --- | --- |
| Что узнаём | доля перебоев у участников при свободном остатке пакета против неоплаты и ограничений [E028]; воронка запуска групп: создана → принято → первое действие [E026]; доля приглашённых, пришедших от других операторов [E062] |
| Данные | ограничения по причине за 3 месяца по номерам участников и остаток пакета группы в момент ограничения; события групп последнего квартала; учёт обращений с разметкой причины, повторы склеены по случаю |
| Порог | доля перебоев при свободном остатке ≥ 30 % — проверка Б идёт; ниже — Б заменяется предупреждением о платеже [E028] |
| Кто | аналитик (0,5 ставки) с владельцем системы расчётов [E085] |

## Проверка А. Запуск группы

| Поле | Значение |
| --- | --- |
| Гипотеза | Если новым группам добавить напоминания о приглашении и первое действие при присоединении, доля активированных за 14 дней вырастет на 7 п.п. — прогноз: две трети отставания — меньше подключённых групп [E022], предположительно из-за слабого запуска [E026][E044] |
| Целевая метрика | доля групп, совершивших первое полезное действие за 14 дней от создания, среди всех созданных, включая приглашения без ответа [E010] |
| Кто участвует | только новые группы, созданные с 1 июня; организаторов случайно делим 50/50 в момент создания группы. В проверке Б эти группы не участвуют — схемы не пересекаются |
| Защитные метрики | отказы от приглашений и отзывы согласия — не больше чем на 2 п.п. выше сравнения; жалобы на напоминания [E081] |
| Срок | к 30.09 (~875 групп на вариант) различим рост от 6,7 п.п.; к 30.11 (~1 375) — от 5,4 п.п. [E082] |
| Решение по итогам | 30.09: рост ≥ 7 п.п. — запуск на все новые группы с 1 октября; иначе набор до 15.11. 30.11: рост ≥ 6 п.п. — запуск с 1 декабря; меньше — чинить запуск иначе (текст приглашения, согласия) [E081][E082] |
| Допустимый разброс | полуширина 95-процентного интервала не больше 3 п.п.; шире — данных недостаточно [E081] |

## Проверка Б. Сигнал до перебоя

| Поле | Значение |
| --- | --- |
| Гипотеза | Если организатор получает предупреждение до исчерпания доли, доля номеров с ограничением из-за исчерпания объёма за 7 дней после первого низкого остатка снизится на 5 п.п. с 25 % — прогноз [E027][E047] |
| Целевая метрика | доля подходящих номеров участников, у которых в течение 7 дней после первого подходящего случая низкого остатка интернет ограничили из-за исчерпания объёма [E081] |
| Первый подходящий случай | у участника осталось меньше порога его доли, в пакете есть свободный остаток, тариф разрешает выделение, согласие действует — регистрируется одинаково в обеих группах |
| Кто участвует | группы, созданные до 1 июня; распределяем всю семью (действие одного меняет остаток другого) случайно 50/50; повторные случаи того же номера не входят |
| Кого считаем | всех включённых, в том числе тех, кто не открыл предупреждение и ничего не сделал |
| Защитные метрики | ложных предупреждений ≤ 5 %; перебоев у другого участника не больше чем на 1 п.п. выше сравнения; двойных выделений — 0 [E081] |
| Срок | нужно 2 880 групп — 66 % всей подходящей базы ~4 350; с убыванием пула набор ~11 недель + 7 дней — к 31.08. В неблагоприятном сценарии база ~3 260 и набор ~30 недель: к 31.08 вывода не будет. Меньше 4,1 п.п. не различить при любом сроке [E086] |
| Порог для расширения | снижение ≥ 5 п.п. и доля правильно исполненных операций ≥ 99 % [E081][E086] |
| Решение по итогам | порог пройден — расширяем на все подходящие группы с 1 сентября, сохраняя 10 % сравнения среди впервые подходящих; интервал включает и пользу, и ноль — данных мало, добор до 30.11; эффект только на одном тарифе — проверить на новых клиентах с этим тарифом [E081] |
| Нежелательные последствия | у другого участника стало не хватать общего пакета; организатор видит сведения после отзыва согласия — пилот останавливается до исправления |

## Проверка В. Работа услуги (первые 4 недели пилота — к 30.06)

| Поле | Значение |
| --- | --- |
| Метрика | доля подтверждённых выделений, которые система расчётов исполнила правильно и в установленный срок; незавершённые — отдельно |
| Порог | не меньше 99 %; повторных списаний и двойных выделений — 0 [E081] |
| Проверка удобства (до пилота, Q1) | 8–10 человек решают одну задачу привычным способом и новым, порядок меняется; кто справился без подсказки, ошибки, время [E081] |

## Удержание — позже

Оплаченные месяцы считаем по платежам номеров исходных групп сравнения, в том числе после выхода номера из группы, через
3 месяца (к 30.11) и 6 месяцев (к концу года) после старта пилота. Это главный множитель прибыли [E036][E075]: снижение
перебоев за неделю само по себе ещё не говорит о числе оплаченных месяцев.
