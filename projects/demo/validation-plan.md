# План проверки

> Методика: `knowledge/methods/experiments.md`. Размеры выборок — `calc/pilot.py`. Пороги записаны до запуска.

## Проверка 0. Данные оператора до пилота (1-й квартал)

| Поле | Значение |
| --- | --- |
| Что узнаём | доля перебоев у участников при свободном остатке пакета против неоплаты и ограничений [E028]; воронка запуска групп: создана → принято → первое действие [E026]; доля приглашённых, пришедших от других операторов |
| Данные | ограничения по причине за 3 месяца по номерам участников и остаток пакета группы в момент ограничения; события групп последнего квартала; учёт обращений с разметкой причины, повторы склеены по случаю |
| Порог | доля перебоев при свободном остатке ≥ 30 % — проверка Б идёт; ниже — проверка Б заменяется предупреждением о платеже [E028] |
| Кто | аналитик (0,5 ставки) с владельцем системы расчётов |

## Проверка А. Запуск группы

| Поле | Значение |
| --- | --- |
| Гипотеза | Если новым группам добавить напоминания о приглашении и первое действие при присоединении, доля активированных за 14 дней вырастет на 7 п.п. — прогноз, потому что две трети отставания — недозапущенные группы [E022][E026][E044] |
| Целевая метрика | доля групп, совершивших первое полезное действие за 14 дней от создания, среди всех созданных, включая приглашения без ответа [E010] |
| Единица и распределение | новая группа; организаторов случайно делим 50/50 в момент создания группы |
| Защитные метрики | доля отклонённых приглашений и отзывов согласия не выше контроля более чем на 2 п.п.; жалобы на напоминания [E058] |
| С чем сравниваем | группы с обычным обслуживанием, созданные в те же недели |
| Срок | к 30.06 (~750 групп на вариант) заметим эффект от 7,3 п.п.; к 30.09 (~1 500) — от 5,1 п.п. [E061] |
| Решение по итогам | рост ≥ 5 п.п. и защитные в норме → запуск на все новые группы в Q3; рост < 3 п.п. → чинить запуск иначе (текст приглашения, согласия); между — продлить набор на Q3 [E058] |
| Нежелательные последствия | раздражение от напоминаний; приглашённые отказываются, увидев объём запрошенных сведений [E014] |

## Проверка Б. Сигнал до перебоя

| Поле | Значение |
| --- | --- |
| Гипотеза | Если организатор получает предупреждение до исчерпания доли, доля номеров с ограничением из-за исчерпания объёма за 7 дней после первого низкого остатка снизится на 5 п.п. с 25 % — прогноз [E027][E047] |
| Целевая метрика | доля подходящих номеров участников, у которых в течение 7 дней после первого подходящего случая низкого остатка интернет ограничили из-за исчерпания объёма [E058] |
| Первый подходящий случай | у участника осталось меньше порога его доли, в пакете есть свободный остаток, тариф разрешает выделение, согласие действует — регистрируется одинаково в обеих группах |
| Единица и распределение | вся семейная группа (действие одного меняет остаток другого) — случайно 50/50; повторные случаи того же номера в расчёт не входят |
| Кого считаем | всех включённых, в том числе тех, кто не открыл предупреждение и ничего не сделал |
| Защитные метрики | ложные предупреждения; выделения, после которых перебой у другого участника; двойные выделения |
| Срок | −5 п.п.: ~7 недель набора на 1 440 групп на вариант + 7 дней; −3 п.п.: ~20 недель на 4 000 групп — к концу Q3 [E060] |
| Порог для расширения | снижение ≥ 3 п.п. и доля правильно исполненных операций ≥ 99 % [E058] |
| Решение по итогам | порог пройден → расширяем на все подходящие группы и сохраняем 10 % в группе сравнения среди впервые подходящих; диапазон оценки включает и пользу, и ноль → данных мало, добор до конца Q3; эффект только на одном тарифе → проверить на новых клиентах с этим тарифом [E058] |
| Нежелательные последствия | у другого участника стало не хватать общего пакета; организатор видит сведения после отзыва согласия — пилот останавливается до исправления |

## Проверка В. Работа услуги

| Поле | Значение |
| --- | --- |
| Метрика | доля подтверждённых выделений, которые система расчётов исполнила правильно и в установленный срок; незавершённые запросы — отдельно |
| Порог | ≥ 99 %, повторных списаний и двойных выделений — 0 [E058] |
| Сравнение | проверка удобства до пилота: 8–10 человек решают одну задачу привычным способом и новым, порядок меняется; записываем, кто справился без подсказки, ошибки и время [E058] |

## Удержание — позже

Оплаченные месяцы считаем по платежам номеров исходных групп сравнения, в том числе после выхода номера из группы,
через 3 и 6 месяцев после пилота. Это главный множитель прибыли [E036][E043]: снижение перебоев за неделю само по себе ещё не говорит о числе оплаченных месяцев.
