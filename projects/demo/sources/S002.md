# МегаФон: россияне стали чаще делиться минутами и гигабайтами с близкими (iPhones.ru, 26.06.2025)

Фрагмент страницы из поисковой выдачи (страница не открывалась целиком).

По данным МегаФона, с начала года число абонентов, которые делятся своими гигабайтами, минутами и SMS с родными, выросло почти на четверть.

Возможность поделиться своим тарифом нравится миллионам наших клиентов по всей России.

Кроме этого, участники получают дополнительные гигабайты интернета каждый месяц, чтобы трафика хватило на все цифровые задачи.
