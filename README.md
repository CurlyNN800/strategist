# strategist

ИИ-агент «Стратег Фабрики продуктов»: от размытого запроса руководителя продукта
до проверяемой картины ситуации, вариантов и согласованных продуктовой
и коммуникационной стратегий.

> Черновик. Инструкция запуска появится к шагу 19.

## Структура

| Папка | Что внутри |
| --- | --- |
| `AGENTS.md` | главные правила агента (читают все среды) |
| `CLAUDE.md`, `.cursor/rules/` | адаптеры под Claude Code и Cursor |
| `skills/` | процедура для каждого этапа работы |
| `agents/` | промпты субагентов: red-team, auditor, respondent |
| `knowledge/` | методички, шаблоны результатов, рубрика качества |
| `scripts/` | команды CLI: сбор, состояние, проверка, стоимость |
| `projects/` | папка на каждую задачу; `_example/` — образец форматов |
| `docs/` | архитектура, форматы данных, совместимость сред |
