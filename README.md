# Стратег Фабрики продуктов

ИИ-агент, который ведёт руководителя цифрового продукта от размытого запроса
(«почему падает удержание?», «кому продавать новый сервис?») до:

- **проверяемой картины ситуации** — что известно, откуда, и чего мы не знаем;
- **нескольких разных вариантов** — включая «оставить как есть» — с сильными возражениями;
- **согласованных продуктовой и коммуникационной стратегий** и плана проверки.

Это не программа, а папка с инструкциями, знаниями и скриптами. Её открывают в ИИ-среде
разработки — агентом становится сама среда, прочитав `AGENTS.md`.

## Быстрый старт (5 минут)

**Нужно:** Python 3.10+ и одна из сред: Claude Code, Cursor, Codex или другая, читающая `AGENTS.md`.

```bash
git clone <адрес репозитория>
cd strategist
pip install -r requirements.txt
python scripts/selftest.py              # самопроверка всех скриптов: «Пройдено 16 из 16»
```

Откройте папку в среде и напишите агенту, например:

> Почему у нашего сервиса упало удержание новых пользователей? Вот выгрузка по когортам: data/cohorts.xlsx

Агент сам заведёт задачу в `projects/<имя>/`, задаст несколько уточняющих вопросов
и пойдёт по этапам. Всё, что он делает, видно в файлах задачи.

**Ключи API не нужны** для работы агента: модель даёт сама среда. `.env` нужен только если
вы подключаете отдельную дешёвую модель для маршрутизации (см. `docs/routing.md`).
Платные сервисы: подписка на выбранную среду. Веб-поиск — встроенный в среду.

## Как с ним работать

| Скажите | Что произойдёт |
| --- | --- |
| своими словами задачу | новая задача, этап «постановка» |
| «статус» | этап, сделанное, открытые вопросы, расходы |
| «стоп» | агент сохранит состояние и скажет, с чего продолжит |
| «продолжи» (в том числе в новом чате или другой среде) | продолжит с места остановки, не повторяя сделанное |
| «исправь …» | исправит и запишет в журнал, что изменилось |
| «новые данные: …» | найдёт затронутые выводы и обновит их |

На двух шагах агент **обязательно** останавливается и ждёт вас: подтверждение постановки
и выбор варианта. Решение принимает человек.

## Этапы

1. **Постановка** → `brief.md`
2. **Сбор материалов** (сайты, PDF, DOCX, XLSX, изображения) → `sources/`, `sources.yaml`, `evidence.jsonl`
3. **Исследование** → `situation.md`
4. **Варианты** + возражения субагента red-team → `options.md`
5. **Выбор человеком** → `decision.md`
6. **Стратегии** + проверка субагентом auditor → `product-strategy.md`, `comms-strategy.md`
7. **План проверки и отчёт** → `validation-plan.md`, `report.md`

После решения — **пересмотр**: новые данные → `revise.py` находит затронутые выводы.

## Почему выводам можно доверять

Каждое утверждение в результатах помечено `[E012]` — ссылкой на запись реестра
`evidence.jsonl`. У записи есть тип (**факт / гипотеза / прогноз / синтетика**), источник и место
в нём; копия источника лежит в `sources/`. `scripts/validate.py` не даёт показать результат, если:
метка ведёт в никуда, факт без источника, отозванная запись используется как основание,
ответ модельного респондента выдан за факт, обещание коммуникации не опирается на продукт.

## Устройство

```
AGENTS.md          правила агента (читают все среды)
CLAUDE.md, .cursor/rules/          адаптеры сред
skills/            процедура каждого этапа, пересмотр, интервью
agents/            субагенты red-team, auditor, respondent (+ копии в .claude/, .gigacode/)
knowledge/         методички, шаблоны результатов, рубрика качества
scripts/           CLI: состояние, сбор, проверка, пересмотр, стоимость, отчёт
config/models.yaml модели и цены
projects/          задачи; _example — образец всех форматов
docs/              архитектура и форматы, маршрутизация, совместимость сред, smoke-тесты
```

Подробнее: `docs/architecture.md`. Самопроверка скриптов: `python scripts/selftest.py`. Проверка агента в новой среде: `docs/smoke-test.md`.

## Ограничения

- Только открытые данные и материалы пользователя.
- Качество зависит от модели среды; рекомендуем сильную модель для этапов 03–06.
- Модельные респонденты помогают искать гипотезы, но не заменяют реальные интервью.
- Веб-страницы, закрытые авторизацией или защитой от ботов, загрузить нельзя — агент сообщит.
