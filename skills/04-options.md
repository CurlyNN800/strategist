# 04-options — варианты действий

**Цель:** несколько содержательно разных вариантов с честными сильными возражениями.

**Вход:** `brief.md`, `situation.md`, `evidence.jsonl`.

## Шаги

1. Сформулируй не меньше трёх вариантов, которые различаются по сути, а не по степени.
   Обязательно:
   - **«Оставить как есть»** — что будет, если ничего не делать;
   - **«Закрыть или свернуть направление»** — рассмотри всерьёз, даже если отвергнешь;
   - 1–3 активных варианта с разной логикой (например: чинить продукт / менять аудиторию / менять сообщение).
2. Для каждого варианта:
   - суть в одном предложении;
   - на что опирается — метки `[E…]`;
   - что потребует (люди, время, деньги) с учётом ограничений из `brief.md`;
   - ожидаемый эффект — как `forecast` с основанием, не как факт;
   - главные риски.
3. Сильные возражения: передай субагенту `agents/red-team.md` только описание варианта
   и `situation.md`, без твоих аргументов «за». Если субагентов в среде нет — сделай
   то же отдельным проходом, забыв свои аргументы. Возражение должно быть таким,
   которое реально может отменить вариант.
4. Сведи всё в `options.md` по шаблону `knowledge/templates/options.md`: таблица сравнения +
   раздел `## Вариант N. …` на каждый вариант (по этим заголовкам валидатор считает варианты).
   Прогнозы эффекта — `python scripts/evidence.py add <task> --type forecast --basis "…"`.
5. `python scripts/validate.py <task>`.

## Выход

`options.md`, новые записи `forecast` в `evidence.jsonl`.

## Проверка перед переходом

- [ ] ≥ 3 варианта, есть «оставить как есть», «закрыть» рассмотрено.
- [ ] У каждого варианта ≥ 2 сильных возражения.
- [ ] Прогнозы помечены как прогнозы. `python scripts/state.py stage <task> 04-options done`.
