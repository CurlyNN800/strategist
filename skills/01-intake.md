# 01-intake — постановка задачи

**Цель:** превратить размытый запрос в ясную задачу, по которой можно проводить исследование.

**Вход:** сообщение пользователя; файлы, которые он приложил.

## Шаги

1. `python scripts/state.py start "уточнить постановку"`.
2. Выпиши из запроса то, что уже понятно, по пяти пунктам: вопрос, цель, получатель,
   ограничения, доступные данные.
3. По пустым или размытым пунктам задай вопросы — не больше 3–4 за раз и только те,
   ответ на которые изменит следующий шаг. Плохой вопрос: «Расскажите о продукте».
   Хороший: «Падение видно по всем каналам привлечения или в одном?»
   Перед вопросом: `python scripts/state.py wait "<вопросы>"`.
4. Если у пользователя есть предположение о причине — запиши его в `evidence.jsonl`
   как `hypothesis` с основанием «предположение пользователя при постановке».
5. Заполни `brief.md` по шаблону `knowledge/templates/brief.md`
   (образец: `projects/_example/brief.md`). Добавь «что будет хорошим результатом».
6. Покажи `brief.md` пользователю коротко и спроси: «Всё верно?»

## Выход

`brief.md`; при необходимости — записи-гипотезы в `evidence.jsonl`.

## Проверка перед переходом

- [ ] Все пять пунктов заполнены или явно помечены «нет данных».
- [ ] Пользователь подтвердил постановку.
- [ ] `python scripts/state.py done <шаг> brief.md`, этап `01-intake` → `done`.
