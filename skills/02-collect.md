# 02-collect — сбор материалов

**Цель:** собрать источники по вопросам, которые могут изменить решение, и выписать
из них проверяемые утверждения.

**Вход:** `brief.md`.

## Шаги

1. Составь список ключевых вопросов (3–7): ответы на них могут изменить рекомендацию.
   Например: «когда началось падение», «что изменилось в продукте в это время»,
   «что делают конкуренты». Каждый — `python scripts/state.py question <task> add "<вопрос>" "<почему важно>"`.
2. Для каждого вопроса реши, где искать: материалы пользователя, открытые сайты,
   отчёты, отзывы, статистика. Только открытые источники. Адреса ищи встроенным веб-поиском
   среды; выбирай первоисточники (`knowledge/methods/evidence-quality.md`). Обычно хватает 5–10 источников.
3. Каждый источник сохраняй через инструменты, а не пересказом из памяти:
   - сайт → `python scripts/fetch_source.py <task> <url>`;
   - файл пользователя → `python scripts/extract.py <task> <файл>`;
   - сайт не скачался скриптом (403, защита от ботов) → прочитай страницу встроенным инструментом
     среды, сохрани текст в `projects/<task>/tmp-page.md` и выполни
     `python scripts/extract.py <task> projects/<task>/tmp-page.md --url <адрес>`.
   Каждый источник получает id `S…` в `sources.yaml` и копию в `sources/`.
4. Из каждого источника выпиши утверждения: одно утверждение — одна запись, с единицами,
   периодом и местом в источнике — `python scripts/evidence.py add <task> --type fact --source S… --where … --topics … --claim …`.
   Это работа для субагента `agents/extractor.md` на дешёвой модели (`docs/routing.md`):
   вызывай его на каждый источник. Без субагентов — делай сам по тому же файлу.
5. Источник недоступен → шаг `failed`, вопрос остаётся открытым, ищи замену.
6. Модельные респонденты (по желанию, `skills/interview.md`) — только тип `synthetic`.

## Выход

`sources/`, `sources.yaml`, записи в `evidence.jsonl`, обновлённые `open_questions`.

## Проверка перед переходом

- [ ] По каждому ключевому вопросу есть хотя бы один источник или запись «не нашли, потому что…».
- [ ] У каждой записи `fact` заполнены `source` и `where`.
- [ ] `python scripts/state.py stage <task> 02-collect done`.
