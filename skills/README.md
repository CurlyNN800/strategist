Какой файл читать на каком этапе — в таблице «Этапы» в AGENTS.md.

- `01-intake.md` … `07-validation.md` — этапы (черновик v0)
- `revise.md` — пересмотр при новых данных (шаг 14)
- `interview.md` — интервью и модельные респонденты
- `ux-review.md` — разбор интерфейса и пользовательского пути по скриншотам
