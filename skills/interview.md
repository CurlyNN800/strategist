# interview — интервью и модельные респонденты

**Цель:** найти гипотезы о причинах и барьерах (модельные респонденты) и проверить их на
реальных людях (настоящие интервью). Используется на этапах 02–03 и для барьеров на этапе 06.

## А. Гайд интервью

1. Из `situation.md` возьми 2–4 гипотезы, которые сильнее всего влияют на решение.
2. Для каждой — 2–3 вопроса **о прошлом опыте**, а не о будущем и не о мнении:
   - хорошо: «Расскажите, когда вы последний раз…», «Что вы сделали потом?»;
   - плохо: «Вы бы пользовались…?», «Вам нравится идея…?» (люди отвечают из вежливости).
3. Сохрани гайд в `projects/<task>/interview-guide.md`: гипотеза → вопросы → что будет подтверждением.

## Б. Модельные респонденты (синтетика)

1. Опиши 2–3 разные роли из аудитории `brief.md` (ситуация, опыт с продуктом, альтернатива).
   Обязательно одну «неудобную»: ушедший пользователь или тот, кто выбрал конкурента.
2. Для каждой роли — сессия с субагентом `agents/respondent.md` (в средах без субагентов —
   отдельный проход в новом чате с текстом этого файла).
3. Сохрани каждую сессию как источник `sources/S00N.md` и добавь в `sources.yaml` с
   `kind: synthetic`, в `notes` — «СИНТЕТИКА: только для поиска гипотез».
4. Выпиши наблюдения в `evidence.jsonl` **только с `type: synthetic`**.
5. Новые гипотезы — отдельные записи `hypothesis`, в `basis` — «подсказано синтетикой [E…]; не проверено».

**Нельзя:** считать долю респондентов, согласных с чем-то; писать «пользователи хотят…» на основе
синтетики. Валидатор запрещает `fact` из синтетического источника.

## В. Разбор реального интервью

1. Только с согласия собеседника. Имя, телефон, место работы и другие персональные данные
   в репозиторий **не попадают** — замени на «Р1, студентка, 21 год».
2. Транскрипт → `python scripts/extract.py <task> <файл>`, `kind` поправь на `interview`.
3. Выпиши в `evidence.jsonl` записи `fact` с `where` = «Р1, ответ на вопрос 3».
   Это факт о **конкретном человеке**, не о всех.
4. Сведи по гипотезам: сколько собеседников подтвердили, опровергли, не затронули.
   При 5–8 интервью говори о повторяющихся мотивах, а не о долях.

## Выход

`interview-guide.md`, новые источники и записи в `evidence.jsonl`, обновлённые гипотезы.
